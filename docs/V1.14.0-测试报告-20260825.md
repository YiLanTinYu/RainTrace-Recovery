## 安全边界

源介质始终只读，恢复输出必须位于另一物理磁盘。V1.14.0 不处理物理坏盘、SSD TRIM 绕过、已覆盖数据、RAID/NAS 重组、无密钥 BitLocker/EFS、APFS/HFS/EXT/ZFS/ReFS，也不写回 GPT、MBR、引导区、FAT 或 MFT。元数据不存在时不承诺原文件名，RAW 内容恢复只使用临时名。
