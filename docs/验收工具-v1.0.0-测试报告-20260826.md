# 雨痕恢复验收工具 V1.0.0 测试报告

测试日期：2026-08-26
目标平台：Windows x64 / .NET 8 自包含发布

## 结论

验收工具已达到发布条件：解决方案 Release 重新编译 0 警告、0 错误；现有恢复核心回归和 WPF 自动化全部通过；自包含 EXE 可独立生成标准文件集、比较恢复结果并输出三种报告。

## 覆盖内容

- 生成 13 个唯一 SHA-256 的标准文件，共 4,202,106 字节。
- 文件集覆盖中文名、空格、深层目录、PNG、GIF、BMP、TXT、CSV、JSON、PDF、DOCX、XLSX、ZIP、WAV 和 4 MiB 数据文件。
- 所有已注册预检格式均通过雨痕结构预检。
- 自动化验证“完整（原路径）”“完整（原名）”“完整（已改名）”“损坏”“缺失”和“额外文件”分类。
- 完整模拟恢复结果为 13/13，内容完整率、原名保留率和原路径保留率均为 100%。
- JSON、CSV 和 Markdown 报告均成功输出。
- 对不存在或非空的生成目录执行安全拒绝，不覆盖现有文件。
- 工具本身不包含删除、格式化或覆盖介质功能。
