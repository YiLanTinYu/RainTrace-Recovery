# 雨痕数据恢复

Windows x64 只读数据恢复工具，面向 16 TiB 以下、仍能被 Windows 正常识别和读取的机械硬盘、SSD、TF/SD 卡、U 盘和移动硬盘。V1.15.2 保留 The Sleuth Kit 4.15.0 + PhotoRec 7.2 + 雨痕只读原生扫描器架构，聚焦误删除、快速格式化/RAW、分区丢失以及常见文件系统元数据损坏。

品牌标志以“雨滴、数据轨迹和回返箭头”组成：雨滴代表“雨”，盘片般的轨迹代表删除后留下的“痕”，回返箭头代表数据恢复。规范见 [品牌视觉规范](docs/品牌视觉规范.md)。

## 直接使用

获取正式发布包后，双击 `dist\雨痕数据恢复-v1.15.2-win-x64\雨痕数据恢复.exe`，接受 Windows 管理员权限提示。发布包面向 Windows x64，基于稳定版 .NET 8 并采用自包含发布，不需要另装 .NET。

1. 选择源物理磁盘，或用“打开镜像”选择 `.img/.dd/.raw/.bin`。
2. 选择“误删除文件”、“快速格式化 / RAW”或“分区丢失”。默认只显示对应的自动扫描阶段；六个专业选项收纳在“高级设置”。
3. 如果计划包含 PhotoRec，先选择与源介质不同的物理磁盘作为恢复工作目录。PhotoRec 的图片和常见文档默认启用，音视频和压缩包按需勾选；文本文件只走元数据恢复，不做无边界全盘雕刻。
4. 扫描期间可浏览已稳定候选，扫描后按路径、日期、大小、类型、质量、结构和发现方式筛选。
   可逐项勾选多个文件，表头“全选”只作用于当前筛选结果；也支持 Ctrl/Shift 多选行。
5. 将恢复目录设在另一块物理磁盘，点击“恢复选中文件”。每次批量恢复都会生成 JSON 和 CSV 报告。

磁盘下拉框会显示 Windows 物理磁盘编号、该物理盘包含的盘符、硬件型号、容量和总线类型，例如 `物理磁盘 1 · … · 盘符 D: · 953.87 GiB · RAID`。没有挂载盘符的设备显示“无盘符”。若列表为空，程序会明确提示是否缺少管理员权限；NVMe RAID 驱动使用 `GENERIC_READ` 只读句柄枚举，不申请写权限。

重要：发现误删后应立刻停止使用源盘。SSD 上已被 TRIM 的数据通常无法由软件恢复；本工具会把读到全零的候选标记为 `TrimmedOrZeroed`，不会虚假承诺恢复。

## 恢复验收工具

`雨痕恢复验收工具`可以生成 13 个标准测试文件及 SHA-256 清单，并在恢复后自动统计内容完整率、原文件名保留率、原路径保留率、损坏、缺失和额外文件。工具只负责生成和比较文件，不会自动删除或格式化介质。使用方法见 [恢复验收工具使用说明](docs/恢复验收工具使用说明.md)。

- 扫描会话 v3 保存源介质多点指纹、执行选项、扫描目标、阶段状态、字节位置、候选索引、备用元数据和 PhotoRec 稳定暂存文件；可读取 v2 会话。原生阶段按字节位置续扫，TSK/PhotoRec 仅在阶段边界续作。
- 结果中心提供目录树、平铺列表和图片缩略图；图片缩略图懒加载，文本可只读预览，PDF/Office 只显示结构与基本信息。结果表使用虚拟化、分批导入和防抖搜索，同内容候选合并显示并保留备用恢复来源。
- 常见结构回退包括 MBR 扩展分区/EBR 链、主/备 GPT、FAT32 备用引导区与 FAT1/FAT2、NTFS `$MFTMirr` 以及 exFAT 备用启动区；分区候选同时标注证据、可信度和重叠冲突。
- 保守成像先以 4 MiB 读取，失败后拆分为 64 KiB，再递归到逻辑扇区；仅对真正不可读扇区填零并生成坏区地图。镜像、检查点或源指纹不一致时拒绝覆写已有文件。
- The Sleuth Kit 4.15.0 是文件系统元数据主引擎：流式枚举已删除目录项、保留原名与路径，并按元数据地址恢复；Windows 中文输出已做 CP936/UTF-8 适配，不在内存中缓存完整命令输出。
- TSK 返回的同路径、大小和修改时间的历史重复记录合并为一个逻辑结果并保留备用元数据地址；支持直接图片预览和恢复前结构预检，主记录损坏时自动尝试通过预检的备用地址。
- 对实测递归遍历较慢的 exFAT 介质，采用 TSK 快速根目录扫描与雨痕 exFAT 目录树解析组合，结构信息更完整的结果覆盖重复项；NTFS仍使用TSK递归主扫描。
- Windows WPF 中文图形界面，管理员启动，源磁盘只申请读取权限。
- 扫描结果中心：按名称/原路径搜索，按文件类型、恢复质量和发现方式筛选，仅显示可恢复候选。
- 图片只读预览、扫描结果会话保存/重开和当前筛选清单 CSV 导出。
- 恢复前与恢复后可检查 PNG、JPEG、GIF、TIFF、BMP、WEBP、PDF、ZIP/Office OpenXML、旧版 DOC/XLS/PPT、WAV、MP3、MP4/MOV、AVI、RAR 和 7Z 结构；字节虽已写出但结构损坏时明确警告并把质量降为 `Poor`。RAR 仅验证归档签名和基础头，加密内容、分卷连续性及内部文件 CRC 仍需解压器最终确认。
- 文本预检支持 TXT、CSV、LOG、INI、JSON、XML、YAML/YML，识别 UTF-8、UTF-16、UTF-32 和 GB18030/GBK；检查乱码、零字节和可读字符比例，JSON/XML 执行完整语法解析，CSV 检查引号闭合及主要列结构。普通文本没有可靠结束标记，因此“文本可读”不等于内容一定未截断。Markdown 暂不列入 V1.15.2 能力表。
- JPEG自动抢救：文件开头被覆盖但DQT/SOF/DHT/SOS与图像数据仍完整时，保留损坏原件并另存 `.salvaged.jpg`；界面标明“画面已抢救”、尺寸和丢失的EXIF等前置元数据，不用伪造的完整性替代原件。
- 恢复前结构预检：选中文件后只读检查头尾关键结构，结果表显示“预检通过/结构损坏/未预检”，并可按结构状态筛选。
- 雨痕原生扫描器支持在字节读取边界暂停和继续；外部 TSK/PhotoRec 引擎只支持取消和阶段级续作，运行时“暂停”会明确标为不可用，不伪造可恢复的精确百分比。
- MBR、GPT 和无分区表整盘识别；所有容量、LBA、字节偏移使用 64 位整数。
- GPT主头、条目表或CRC损坏时自动验证并读取磁盘末尾的备份GPT；主表和备份表都不可用时保留整盘只读搜索范围，不因异常中止。
- 丢失分区搜索可从NTFS卷末尾备份引导扇区和exFAT第12扇区备份启动区反推出原分区起点，并把备份几何信息交给原生元数据扫描器继续恢复文件；全过程不重写MBR/GPT或文件系统引导区。
- NTFS Boot Sector、MFT、USA fixup、驻留/非驻留 `$DATA`、runlist、目录路径重建。
- exFAT Boot、活动 FAT、分配位图、已删除 File/Stream/FileName 条目集、UTF-16 原文件名和目录路径、精确 64 位文件长度。
- exFAT 连续分配与保留 FAT 簇链的碎片文件恢复；簇链已被清除时仍显示原文件名和大小，并明确标记为不可可靠恢复。
- exFAT深度元数据：目录树损坏时顺序搜索整个簇区，只有通过条目组合、校验和、名称和数据范围验证的孤立删除记录才进入结果，并与普通目录结果去重。
- FAT32 短文件名、Unicode LFN长文件名、父目录和簇链恢复；FAT链已清除时按连续簇保守推断并标记为 `Partial`。
- 可选逐扇区搜索丢失的NTFS、exFAT和FAT32引导记录，从分区表丢失的介质中重新建立扫描范围。
- NTFS 深度元数据扫描：在当前有效 MFT 之后只读检查 512 MiB，搜索旧 `FILE` 记录，恢复残留的原文件名和父目录。
- 全盘旧 MFT：逐块搜索整个 NTFS 卷，不依赖旧记录仍位于当前 MFT 附近；排除当前 MFT 物理范围，并用 USA fixup、属性边界、记录号和数据簇范围多重校验抑制误报。此模式会读取整卷，耗时取决于介质容量和速度。
- 使用 NTFS `$Bitmap` 判断原簇是否复用，并检测 SSD TRIM/零化的常见结果。
- JPG、PNG、BMP、WEBP、PDF、ZIP、DOCX、XLSX、PPTX、WAV、连续MP4/MOV文件扫描；BMP/RIFF/ISO-BMFF优先使用格式长度与容器盒结构确定边界。
- JPG 扫描跳过 EXIF 内嵌缩略图，避免把缩略图结束标记误判为整张照片结尾。
- PhotoRec 7.2 已替换界面中的自研弱特征扫描：作为深度兜底默认不勾选；启用时只扫描未分配空间、严格校验并拒绝损坏候选。
- PhotoRec 结果先安全写入目标盘的 `PhotoRec-Staging`，随后进入雨痕列表，可预览、预检、勾选并复制到正式 `PhotoRec Recovery` 目录；取消扫描会终止子进程并保留已写出的阶段性文件。
- PhotoRec 与元数据候选在扩展名、精确大小和完整内容 SHA-256 一致时合并，优先保留元数据中的原文件名与路径。
- 恢复文件 SHA-256、同名避让、路径净化、取消操作。
- 原盘到镜像的只读复制、分级拆分读取、真正不可读扇区零填充、坏区地图、JSON 检查点续传和 SHA-256。
- 阻止把恢复文件或新镜像写回源物理磁盘。
- 保存扫描结果时记录源介质容量、扇区、型号、序列号和首扇区SHA-256；重新打开时不一致即阻止恢复，避免物理磁盘编号复用导致选错盘。
- 运行日志和未处理异常写入 `%LOCALAPPDATA%\RainTrace\Logs`，便于定位驱动、TSK和PhotoRec异常。

## 边界

- 本工具只做软件级、常见逻辑故障恢复。不处理物理坏盘、磁头/固件/主控/芯片级问题，不绕过 SSD TRIM，不恢复已被覆盖的数据。
- 仅覆盖 Windows x64、单块可识别介质、NTFS/exFAT/FAT 和小于 16 TiB 的目标。不做 RAID/NAS 重组、网络/远程恢复、APFS/HFS/EXT/ZFS/ReFS，不破解 BitLocker/EFS 密钥。
- 所有源介质永久只读；不写回分区表、引导区、FAT 或 MFT。恢复输出必须在另一物理磁盘。
- FAT12/16/32 的常规元数据由 TSK 解析，FAT32 同时有雨痕原生备用引导区和第二 FAT 回退；FAT 删除后若簇链已清除，碎片文件仍可能无法完整重组。
- exFAT 删除后若 FAT 簇链已清除，非连续文件可能只能保留原名和大小；连续分配文件仍可依据 Stream Extension 恢复。目录项被覆盖后会自动降级为文件特征扫描。
- 深度/全盘旧 MFT 只能找回仍保留完整 FILE 记录的名称；元数据不存在时，RAW 内容恢复只能使用临时名，不承诺原文件名。不做 `$LogFile/$UsnJrnl` 猜名、NTFS 去重或复杂属性列表重建。
- 不做无边界文本雕刻、碎片视频猜测拼接、AI 照片/视频修复，不提供虚假的精确恢复成功率。
- 这是小范围使用的恢复工具，不代替取证级写保护器。硬件状况异常的介质应停止扫描并交给专业成像设备。

## 与开源恢复引擎的关系

1.7.0 起，官方 The Sleuth Kit 4.15.0 是 NTFS/exFAT/FAT 元数据与原文件名恢复主引擎。雨痕不重复实现成熟文件系统解释，只负责 Windows 只读设备访问、安全编排、中文路径适配、候选去重、交互和恢复后校验。上游源码、固定归档与许可证说明见 `third_party`。

项目已引入官方 TestDisk/PhotoRec 7.2 源码，固定提交为 `281be432dd79121e08e0898887a9ee1f30fb3e96`。雨痕保留 WPF 图形界面和 NTFS/exFAT/FAT32 原文件名恢复，逐步使用 PhotoRec 的文件格式数据库、严格校验和未分配空间扫描替换自研特征扫描。源码位于 `third_party/testdisk`，许可证见 `third_party/testdisk/COPYING`。

1.6.0 起发布包内置 PhotoRec 引擎、GPL 许可证和对应的 7.2 完整源码压缩包。1.5.6 是切换前最后一个使用自研特征扫描的发行版。

1.6.1 将 exFAT 中同一路径、大小和修改时间的多代删除目录记录合并为一项；不同物理位置的副本仍保留在内存中，恢复时会在主副本结构预检失败后自动尝试备用副本。

1.6.2 完善结果表多选：支持 Ctrl+A 全选当前结果、Shift 连续选择、Ctrl 增减单项；行选择与复选框勾选取并集进行恢复。选中行使用高对比蓝色背景和浅蓝左侧指示条。
